# TalyAqua

## Proje Hakkında

TalyAqua, staj sürecinde Flutter ve Dart kullanılarak geliştirilen mobil bir AquaPark yönetim uygulamasıdır. Uygulama, AquaPark içerisindeki günlük operasyonların takip edilmesini kolaylaştırmak amacıyla geliştirilmiştir.

Sistem, REST API üzerinden aldığı verileri gerçek zamanlı olarak kullanıcıya sunmaktadır. Günlük satışlar, gelir analizleri, ödeme bilgileri, bilet detayları ve istatistiksel veriler modern ve kullanıcı dostu bir arayüz ile görüntülenmektedir.

# Teknolojilerin Kullanım Amaçları

### Flutter

Tek bir kod tabanı kullanılarak Android ve Web platformları için uygulama geliştirilmesini sağlamaktadır.

### Dart

Uygulamanın tamamının geliştirildiği programlama dilidir.

### RxDart

Reaktif programlama yapısını sağlayarak uygulama içerisindeki veri akışının yönetilmesinde kullanılmıştır.

### BehaviorSubject

Son veriyi hafızasında tutarak veri değişikliklerinin arayüze anlık olarak aktarılmasını sağlamaktadır.

### StreamBuilder

BehaviorSubject üzerinden yayınlanan verileri dinleyerek ekranın otomatik olarak güncellenmesini sağlamaktadır.

### GetIt

Dependency Injection yapısını sağlayarak servislerin merkezi bir noktadan yönetilmesini sağlamaktadır.

### Easy Localization

Uygulamanın Türkçe ve İngilizce dillerini desteklemesini sağlamaktadır.

### Flutter Secure Storage

Kullanıcı giriş bilgilerinin güvenli şekilde cihaz içerisinde saklanmasını sağlamaktadır.

### HTTP

REST API ile haberleşmek ve sunucudan veri almak amacıyla kullanılmaktadır.

### REST API

Dashboard, günlük satışlar, ürünler, ödemeler ve diğer tüm verilerin uygulamaya aktarılmasını sağlamaktadır.

### Material Design

Modern, sade ve kullanıcı dostu arayüzlerin oluşturulmasında kullanılmıştır.
